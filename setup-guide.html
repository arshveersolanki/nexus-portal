Setup Guide

Browser Streaming Setup

You already have Sunshine + Moonlight working. This guide covers setting up Neko for browser-based streaming — so you can play from any device without installing an app.

Step 1

Install Docker on Your PC

Neko runs as a Docker container. You can run it on either your Windows (2TB 990 Pro) or Ubuntu boot drive.

On Windows:

  • Download and install Docker Desktop for Windows
  • Enable WSL 2 backend when prompted
  • Restart your PC after installation

On Ubuntu:

sudo apt update && sudo apt install -y docker.io docker-compose sudo usermod -aG docker $USER # Log out and back in after this
Step 2

Run Neko (WebRTC Streaming Server)

Neko turns your desktop into a browser-accessible stream via WebRTC. Run this command to start it:

Basic command (streams full desktop):

docker run -d --name neko \ -p 8080:8080 \ -p 52000-52100:52000-52100/udp \ -e NEKO_SCREEN=1920x1080@60 \ -e NEKO_PASSWORD=your_password \ -e NEKO_PASSWORD_ADMIN=your_admin_password \ -e NEKO_EPR=52000-52100 \ -e NEKO_ICELITE=true \ --shm-size=2g \ --restart unless-stopped \ ghcr.io/m1k1o/neko/nvidia:latest

Key settings:

  • Port 8080 — the web UI (this is what NEXUS connects to)
  • Ports 52000-52100/udp — WebRTC media transport
  • NEKO_SCREEN — match your monitor resolution. Your 4070 Super can handle 1440p easily: use 2560x1440@60
  • NEKO_PASSWORD — this is the password you'll enter in the NEXUS portal
  • The nvidia tag uses GPU acceleration with your RTX 4070 Super

For GPU-accelerated encoding (recommended):

Install the NVIDIA Container Toolkit first, then add --gpus all to the docker command:

docker run -d --name neko \ --gpus all \ -p 8080:8080 \ -p 52000-52100:52000-52100/udp \ -e NEKO_SCREEN=1920x1080@60 \ -e NEKO_PASSWORD=your_password \ -e NEKO_PASSWORD_ADMIN=your_admin_password \ -e NEKO_EPR=52000-52100 \ -e NEKO_ICELITE=true \ -e NEKO_HWENC=nvenc \ --shm-size=2g \ --restart unless-stopped \ ghcr.io/m1k1o/neko/nvidia:latest
Step 3

Connect from NEXUS Portal

Once Neko is running:

  • Open the NEXUS portal (Remote Play section)
  • Enter your PC's local IP (e.g., 192.168.1.100) — find it with ipconfig on Windows or ip a on Ubuntu
  • Port: 8080 (default)
  • Password: whatever you set in NEKO_PASSWORD
  • Hit Connect — you should see your desktop streaming in the browser

From there, you can open any game (Fortnite, Valorant, etc.) directly in the streamed desktop and play from your browser.

Step 4

Remote Access (Outside Your Network)

To stream games when you're away from home, you need to expose the Neko server to the internet. There are two approaches:

Option A: Port Forwarding (simpler)

  • Log into your router (usually 192.168.1.1)
  • Forward port 8080 (TCP) and 52000-52100 (UDP) to your PC's local IP
  • Use your public IP to connect (find it at whatismyip.com)
  • Consider using a dynamic DNS service (like No-IP) if your public IP changes

Option B: Tailscale / WireGuard VPN (more secure)

  • Install Tailscale on both your PC and the device you're streaming from
  • Use the Tailscale IP (e.g., 100.x.x.x) instead of your public IP
  • No port forwarding needed — encrypted tunnel through NAT
  • This is the recommended approach for security
Step 5

Performance Tips for Your 4070 Super

Your hardware is more than capable. Here are some optimizations:

  • Use NVENC encoding — your 4070 Super's dedicated encoder handles streaming with zero FPS impact on games
  • Ethernet > WiFi — use a wired connection on your PC for the lowest latency
  • Bitrate — for 1080p60, use 15-25 Mbps. For 1440p60, use 25-40 Mbps
  • Resolution — match Neko's NEKO_SCREEN to your game's resolution to avoid scaling
  • Shared memory — increase --shm-size to 4g if you experience frame drops
  • For Fortnite specifically — use Performance Mode in Fortnite settings to maximize FPS headroom while streaming
Help

Troubleshooting

  • Can't connect? — Make sure Docker is running and Neko container is up: docker ps
  • Black screen? — Increase --shm-size to 4g or 8g
  • High latency? — Ensure NEKO_ICELITE=true is set, and use Ethernet
  • No GPU acceleration? — Verify NVIDIA Container Toolkit: docker run --gpus all nvidia/cuda:12.0-base nvidia-smi
  • Audio issues? — Neko handles audio through WebRTC automatically. Check browser permissions
  • Neko docs: github.com/m1k1o/neko
